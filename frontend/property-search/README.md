## Property Search Frontend (Next.js)

UI for the Property Search project. The full-stack setup is documented in `README.md` at the repo root.

## Getting Started

Install dependencies and run the dev server:

```bash
npm install
NEXT_PUBLIC_BACKEND_URL=http://localhost:8000 npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

If you’re running the backend on another host/port, set `NEXT_PUBLIC_BACKEND_URL` accordingly.
